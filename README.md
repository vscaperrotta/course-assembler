# Officina 8 bit

Corso Assembly in italiano con simulatore didattico CPU a 8 bit. Il chip è schematico e ingrandito.

## Avvio

1. Installa Node.js 20.19+ o 22.12+.
2. Esegui `npm install`.
3. Esegui `npm run dev` e apri l’indirizzo indicato da Vite.

Per la build di distribuzione: `npm run build`.
